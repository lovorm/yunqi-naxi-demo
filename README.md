# 「云栖纳西」—— 多源数据融合的乡村文旅数字底座

> 免费 · 零部署 · 面向丽江 20 间房以内纳西小微民宿的文旅数字底座
> 天-地-人-物四源数据融合，全部数据免费公开、逐条可溯源。让数据可读、让生态可感、让纳西回家。

## 在线演示

部署后在此填入：`https://<你的用户名>.github.io/yunqi-naxi-demo/`

## 本仓库即站点

纯静态单页（`index.html` + `vendor/`），无构建步骤：

| 文件 | 说明 |
|---|---|
| `index.html` | 演示页（路线筛选/详情弹窗/生态名片/数据看板，ECharts 本地化） |
| `vendor/tailwind.css` | 预编译样式（25KB，替代 CDN 运行时编译） |
| `vendor/echarts.min.js` | Apache ECharts 5.4.3 |
| `vendor/html2canvas.min.js` | 名片 PNG 导出 |
| `vendor/hero-snow.jpg` | 首屏背景 |

全站零外链，断网/弱网环境可完整渲染。

## 口径说明

- 演示版数据均为**走访素材示例**，页面内逐条标注来源/采集时间/更新频率三要素
- 海拔剖面为演示示意，P1 接入 SRTM 30m DEM 实测
- 项目边界：不做订房、不做支付、不做政府监管
